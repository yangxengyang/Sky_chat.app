# RedChat / SkyChat Vue 3 Application

A modern, high-performance messaging web application built with **Vue 3**, **TypeScript**, **Vue Router 4**, **Pinia**, and **Lucide Vue Next**.

## Features

- 📱 **17 UI Screens** matching the original RedChat Lao design (Splash, Onboarding, Login, Register, Home Chat List, Private Chat, Group Chat, Call Logs, Status/Stories Viewer, Profile, Settings, Privacy, Notifications, Theme, About).
- 🎨 **Red & White Brand Palette** with theme toggle (Red, Light, Dark).
- 💬 **Messaging**: Supports Text, Image attachments with lightbox viewer, Voice messages with animated waveform, and File attachments.
- 📞 **Calls**: Incoming/Outgoing/Missed call logs with audio & video triggers.
- ⭕ **Status/Stories**: Interactive story progress bar and viewer.
- 🔒 **Pinia State Management & Vue Router 4** layout routing.

## Getting Started

```bash
# Install dependencies
pnpm install

# Run dev server
pnpm dev

# Build for production
pnpm build
```
